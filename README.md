# Seven Little Sins — homepage visual preview

An original, responsive homepage for `7deadlysinstest.xyz` with seven illustrated SVG characters, a result-card example, character dialogs, and FAQ accordions.

This revision is limited to homepage visual review. The quiz and inner pages are not connected. The main calls to action open a clearly labeled illustrative result preview.

No dependencies are required. Build with `node tools/build.mjs`, then run `node tools/serve.mjs` and open `http://127.0.0.1:4173/`.

Source: `src/`. Homepage generator: `tools/build.mjs`. Browser-ready output: `dist/`.

The custom domain has not been configured or deployed by this project.
